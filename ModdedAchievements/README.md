# ModdedAchievements

Valheim turns achievements off as soon as a mod marks the game as modded (Jotunn and many other mods do this).
Achievement progress stops counting too: food eaten, creatures slain, fish caught. ModdedAchievements turns them
back on.

- **Only the "modded" mark is ignored.** Real cheating still blocks achievements, exactly like in vanilla: dev
  commands used by your character, cheated world settings and cheated items in your inventory.
- The *Modded* text in the main menu stays, so the game's own support info is still right.
- No settings. Client-side only; works on vanilla servers.

Pairs well with the other achievement helpers:
[AchievementPeek](https://thunderstore.io/c/valheim/p/koendertjh/AchievementPeek/),
[FoodTracker](https://thunderstore.io/c/valheim/p/koendertjh/FoodTracker/),
[FishTracker](https://thunderstore.io/c/valheim/p/koendertjh/FishTracker/),
[BestiaryTracker](https://thunderstore.io/c/valheim/p/koendertjh/BestiaryTracker/),
[PeakFinder](https://thunderstore.io/c/valheim/p/koendertjh/PeakFinder/) and
[ComfortHelper](https://thunderstore.io/c/valheim/p/koendertjh/ComfortHelper/).
